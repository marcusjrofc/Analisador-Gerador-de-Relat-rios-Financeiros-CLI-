# Analisador Financeiro CLI

Um analisador de despesas simples em Python que lê dados de um arquivo CSV, limpa a formatação dos valores e exibe um resumo agrupado por categoria e o total geral.

## 🚀 Funcionalidades
- Leitura e processamento de arquivos CSV.
- Tratamento automático de formatação (remoção de aspas e espaços extras).
- Agrupamento de gastos por categoria.
- Cálculo do valor total de despesas.

## 🛠️ Tecnologias Utilizadas
- Python 3
- Módulo nativo `csv`
